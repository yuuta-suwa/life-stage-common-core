## 5. 自動E2Eの実行方法（開発者向け）

```bash
# 1) ローカル Supabase（Docker）。supabase/config.toml は [auth.mfa.totp] を有効化して使う
npx supabase start -x studio,imgproxy,edge-runtime,logflare,vector,supavisor,mailpit,realtime,postgres-meta
# 2) ローカル用の公開キーで本番ビルドを起動（キーは supabase start の出力。ローカル専用の値）
NEXT_PUBLIC_SUPABASE_URL=http://127.0.0.1:54321 NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=<local publishable> \
NEXT_PUBLIC_SITE_URL=http://localhost:3100 pnpm build && pnpm start -p 3100
# 3) E2E（E2E_LOCAL_SECRET_KEY はローカルのデモ用 secret。本番・検証環境のキーは使わない）
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=<local publishable> E2E_LOCAL_SECRET_KEY=<local secret> node tests/e2e/app01.e2e.mjs
```

`tests/e2e/lib.mjs` は Supabase URL が 127.0.0.1/localhost 以外なら起動を拒否する。
