# TRIAL READINESS｜APP01 5名試験公開の可否判定

判定日：2026-11-19。対象：APP01 THE FINAL DISCOVERY（検証環境 https://life-stage-common-core.vercel.app/apps/APP01）。

## 1. 判定

**技術面は合格。5名の限定試験公開は「条件付きで可」。** 下の §4「公開前に必須」の5項目（発注者の操作と承認）が済んだ時点で招待を始められる。

- 正式仕様書 §15 は「P0 が全受入テストに合格した時点を APP01 公開可能」と定めている。AI 精査・PNG 画像共有・下書き共有（いずれも P0）が未実装のため、**仕様上の「正式公開」には当たらない**。今回の公開は、これらが無いことを参加者に説明したうえでの**限定試験**として扱う（要承認：C-4）。
- 本番公開（有料講座での利用）は対象外。§3 の段階 B で別途判断する。

## 3. Vercel の利用条件と運用案（⑥）

### 3-1. 確認できたこと・できなかったこと
- 検証環境は Vercel チーム **GMPDCASP** の配下にある（プロジェクト `life-stage-common-core`、東京リージョンの関数）。
- **チームの契約プラン（Hobby／Pro）は API から取得できず、未確認。** ダッシュボードの Settings → Billing で確認が必要。
- **最新の規約文面は、この作業環境から vercel.com へ接続できず、原文を確認できていない。** 以下は 2026-11-18 時点の調査（docs/OPERATIONS.md §8）に基づく。採用前に原文で再確認すること。
  - Hobby（無料）は**個人・非商用**の利用に限られる。有料サービスの提供や事業目的の利用は商用とみなされる。
  - Pro は利用者（デプロイ等を行うチームメンバー）1人あたり月額（目安 $20）。サイトの閲覧者（受講者）は課金対象外。

## 5. 参加者への案内に入れる事項（案）

- 招待リンクは本人の Google アカウント専用で、1回限り・72時間有効。
- 回答は自動保存される。本人だけが見られ、管理者も内容は見ない。共有は本人が選んだ内容だけ。
- 現在は AI による精査はない。自分の言葉で確定する。
- 画像（PNG）での共有は準備中。文章のコピー、または印刷から PDF に保存して共有する。
- ビジョンボードの写真はバックアップの対象外。元の写真は手元にも保存しておく。
