# APP02｜SELF-REALIZATION ENGINE 実装状況（Phase 1）

正本：APP02_Official_v1.pdf（統合詳細仕様書 1.0、2026-11-12）。共通基盤と同じ Next.js アプリ・同じ Supabase で動作（`/apps/APP02`）。
AI は組み込まない方針（D-35）。仕様の AI 機能は「ChatGPT に相談する」（本人が相談文をコピーして自分の ChatGPT に貼り付ける）と、ルールベースの推奨・チェックで代替（D-44）。仕様 §19「AI 利用不能時は標準テンプレートと手動入力で継続」の範囲。
